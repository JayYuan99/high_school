## 核心知识点讲解

### 一、区域定位与地理情境

1976年唐山7.8级地震发生在城市人口熟睡时，建筑和基础设施遭到毁灭性破坏，造成巨大伤亡。它说明灾情取决于震级，还与震源深度、人口建筑、发生时间和防震能力有关。

### 二、核心概念与地理要素

#### 1. 地震形成与构造要素

地壳岩层长期受地应力作用发生弯曲变形 → 应力超过岩层承受限度 → 岩层突然断裂或错位 → 能量以地震波向四周传播 → 地面震动。

- 震源：地下岩层最初破裂、能量释放处。
- 震中：震源垂直投影到地面的点。
- 震源深度：震源到震中的垂直距离。
- 震中距：地面某点到震中的距离。

<!-- 图片描述：对应源文图6.11“地震构造示意”。地壳剖面标断层、震源、震中、震源深度和地面观测点震中距；同心波纹表示地震波传播，地表建筑随距离和地基条件显示不同破坏程度。 -->

#### 2. 震级与烈度

震级表示一次地震释放能量大小，一次地震只有一个震级。烈度表示某地地面受影响和破坏程度，一次地震在不同地点有多个烈度。

烈度主要受震级、震源深度、震中距影响，也受地质基础、地形、建筑抗震性能等影响。震中距相同，软弱沉积层可能放大震动，建筑质量差的地区破坏更重。

#### 3. 滑坡

滑坡是斜坡岩土体在重力作用下，因河流冲刷、地下水、地震或工程活动等沿滑动面整体下滑。形成常需：坡度和高差、破碎松散岩土、软弱面或结构面，以及降雨、地震、开挖等触发。

<!-- 图片描述：对应源文图6.12“滑坡”。山坡剖面显示后缘裂缝、滑坡壁、沿弧形滑动面整体下滑的岩土体和前缘堆积，山下村庄被掩埋；蓝色地下水箭头和坡脚河流冲刷、道路切坡符号表示自然与人为诱因。 -->

#### 4. 泥石流

泥石流是山区沟谷中由暴雨或冰雪融水激发、含大量泥沙石块的特殊洪流。三个核心条件：

1. 陡峻沟谷，提供势能和汇流通道。
2. 丰富松散物质，提供固体物源。
3. 短时间大量水流，提供启动和搬运动力。

<!-- 图片描述：对应源文图6.13“泥石流”。从上游形成区、中游流通区到下游堆积区的完整沟谷，暴雨汇流裹挟泥沙巨石高速下泄，冲毁铁路道路并在沟口形成扇形堆积；三项条件用图标标出。 -->

#### 5. 滑坡与泥石流比较

| 项目 | 滑坡 | 泥石流 |
|---|---|---|
| 运动物质 | 岩土体 | 水、泥沙、石块混合物 |
| 运动方式 | 沿滑动面整体下滑 | 沿沟谷快速流动 |
| 地形 | 斜坡 | 陡峻沟谷和汇水区 |
| 水的作用 | 增重、润滑、提高孔隙水压力 | 是混合洪流的必要组成与动力 |
| 主要危害 | 掩埋、推毁、堵江 | 冲毁、淤埋、堵江，速度快 |

### 三、过程机制与成因链条

#### 1. 地震灾害链

地震强震动 → 房屋道路管线破坏；同时使山体失稳 → 崩塌滑坡 → 堵塞河流形成堰塞湖 → 溃决引发洪水；海底地震还可引发海啸，城市管线破坏可引发火灾和有毒气体泄漏。

#### 2. 暴雨—滑坡链

持续或强降雨 → 水进入岩土体、重量增加 → 孔隙水压力升高、抗剪强度下降 → 软弱面失稳 → 滑坡。

#### 3. 泥石流全过程

暴雨集中汇流 → 冲刷坡面和沟床松散物 → 固液混合体密度和搬运力增大 → 沿沟谷高速运动 → 沟口坡度减小后堆积、淤埋。

#### 4. 人类活动放大风险

削坡修路、采矿和不合理建设破坏坡体平衡；砍伐植被和弃渣增加松散物源；在沟口冲积扇或滑坡体上建聚落提高暴露度。人类活动一般是诱发或放大因素，不应把所有地质灾害都归为人为造成。

### 四、空间分布、图表判读与证据

#### 1. 地震分布

世界地震集中在环太平洋和地中海—喜马拉雅地带，反映板块边界地壳活动强。我国地跨两大地震带，台湾、西藏、新疆、青海、云南、四川等较频繁。

#### 2. 滑坡泥石流分布

我国山区广，灾害分布广泛，西南最为多发：地形起伏大、构造活动强、岩体破碎、季风降水集中，加之河谷交通建设和聚落暴露度较高。

#### 3. 景观证据

滑坡图找后缘裂缝、滑动面、整体位移和前缘堆积；泥石流图找沟谷约束、泥水石混合流、冲刷痕迹和沟口堆积。只有堆积扇照片时，还需结合暴雨和物源材料确认。

### 五、人地关系、影响与对策

#### 1. 地震影响

直接造成房屋倒塌、人员伤亡和道路管线通信破坏；次生滑坡、火灾、海啸、泄漏和疫情；长期影响包括生态系统破坏、经济停滞、人口迁移及心理创伤。

#### 2. 风险降低

- 地震：活动断裂调查、抗震设防、避开高风险地段、家具固定、演练和预警。
- 滑坡：排水、削坡减载、抗滑桩和挡墙、监测裂缝，限制坡脚开挖。
- 泥石流：上游水土保持、拦砂坝、排导槽、监测雨量，沟口高风险区规划避让。

工程措施必须与监测、规划和群众转移结合；在活动滑坡体或泥石流沟口继续高密度建设，单靠工程难以消除风险。

### 六、综合题型与迁移应用

#### 1. 震级烈度题

先判问的是地震能量还是某地破坏。能量答震级；某地破坏答烈度，并从震级、震源深度、震中距、地基和建筑解释。

#### 2. 滑坡泥石流条件题

按“地形—物质—水或触发—人类活动—承灾体”作答。泥石流三条件缺一不可，不能只写暴雨。

#### 3. 灾害链题

箭头必须有过程逻辑，不能并列堆灾名。例如“地震→滑坡→堵江→堰塞湖→溃决洪水”，每一步说明触发关系。

## 重点梳理

- 地震：应力积累—断裂错动—地震波—地面震动。
- 一次地震一个震级、多个烈度；烈度受自然和建筑条件共同影响。
- 滑坡：岩土体沿滑动面整体下滑。
- 泥石流：陡谷＋松散物＋短时大量水流。
- 地质灾害高发不等于必然成灾，规划避让和工程设防可降低损失。
- 灾害常关联并形成链条，治理需防次生风险。

## 难点突破

### 1. 震级大不等于任何地方烈度都大

震级固定但能量随传播衰减；浅源、近震中、软土和抗震差建筑可使烈度高。深源地震即使震级较大，地表破坏可能相对小。

### 2. 降雨怎样触发滑坡

水不只是增加重量，还进入裂隙、提高孔隙水压力并润滑软弱面，使岩土抗滑力下降。答题只写“土变重”不完整。

### 3. 泥石流和山洪

山洪以水流为主，泥石流含大量泥沙石块、密度和冲击力更大。二者可相伴发生并相互转换。

### 4. 灾害链不是时间上的随意排列

链条必须存在因果机制。如地震可使山体失稳而滑坡，滑坡堵河形成堰塞湖，堰塞坝溃决才引发下游洪水。

## 例题讲解

### 例1 同一地震两地烈度不同

两地震中距相同，甲位于松软沉积平原且老旧砖房多，乙位于坚硬基岩、建筑抗震好。甲地软土可能放大震动、建筑脆弱，烈度和损失可高于乙地。一次地震震级仍相同。

### 例2 西南泥石流为何多发

西南地形陡峻、沟谷深，构造活动强使岩石破碎、松散物丰富；季风降雨集中、暴雨多，水动力充足；地震、修路采矿和坡地扰动进一步增加物源与失稳，故泥石流多发。

### 例3 教材活动：地震直接引发哪些灾害

地震可直接引发崩塌、滑坡、泥石流、火灾、海啸、有毒气体泄漏等。示例链：地震使山体滑坡 → 滑坡堵塞河道形成堰塞湖 → 堰塞坝溃决 → 下游洪水。学生还可根据本地灾害绘制链条，但需说明每个箭头的机制。

### 例4 滑坡泥石流辨析

若材料描述“坡体出现后缘裂缝，整块土体沿弧形面缓慢位移”，判断滑坡；若描述“暴雨后沟谷中泥水裹挟巨石高速下泄”，判断泥石流。判断依据分别是整体滑动面与沟谷混合洪流。

## 易错点整理

1. 把震级和烈度都理解为地震大小。震级是能量，烈度是某地影响。
2. 认为震中一定是破坏最严重地点。地质和建筑可能改变烈度分布。
3. 把所有山体崩落称滑坡。滑坡有整体滑动面，崩塌以坠落滚动为主。
4. 认为泥石流只需暴雨。还需陡峻沟谷和丰富松散物。
5. 把泥石流等同洪水。固体物含量和运动特征不同。
6. 认为植树可立即彻底阻止所有滑坡泥石流。深层滑坡还受构造和地下水控制。
7. 灾害链中只列名称、不写因果箭头。
8. 只关注物质损失，忽略心理健康和长期恢复。

## 考点考证点整理

### 考点一：地震构造与形成

- 出题思路：给剖面图辨认震源震中，或用断层材料解释地震。
- 关键条件：应力积累、断裂错动、地震波和距离关系。
- 解答要点：按完整过程作答；准确区分震源、震中、震源深度和震中距。
- 易扣分点：把震中写在地下；遗漏能量以地震波传播。

### 考点二：震级与烈度

- 出题思路：比较同次地震不同地点的破坏或不同地震灾情。
- 关键条件：震级、深度、震中距、地基、建筑和人口。
- 解答要点：一次地震一个震级、多地多个烈度；解释差异需自然与社会因素。
- 易扣分点：说某次地震有多个震级；只按距离判断烈度。

### 考点三：滑坡泥石流成因

- 出题思路：给坡度、岩性、降雨和工程活动材料判断风险。
- 关键条件：地形、松散破碎物、地下水或暴雨、触发扰动。
- 解答要点：滑坡强调重力和滑动面；泥石流写陡谷、物源、水源三条件。
- 易扣分点：只写山区暴雨；不区分运动方式。

### 考点四：灾害空间分布

- 出题思路：给板块图、地形降水图说明我国西南高风险。
- 关键条件：板块边界、活动断裂、地势起伏、岩体破碎和集中降雨。
- 解答要点：多图层证据综合，兼顾人类活动和承灾体。
- 易扣分点：只写“位于山区”；不说明地震与暴雨共同提供物源触发。

### 考点五：灾害链与次生灾害

- 出题思路：补全流程图或根据材料设计灾害链。
- 关键条件：先后顺序和每一步物理机制。
- 解答要点：用箭头写完整，如地震—滑坡—堵江—堰塞湖—溃决洪水；提出链式风险监测。
- 易扣分点：并列灾害当链条；箭头方向颠倒。

## 练习题答案

### 1. 基础概念

震级表示一次地震释放能量大小，一次地震只有一个震级；烈度表示某地点受到的影响和破坏程度，同一次地震在不同地点烈度不同。影响因素包括震级、震源深度、震中距、地质地基、地形、建筑抗震性能等。

### 2. 地震构造

岩层长期受地应力发生变形，应力超过承受限度后突然断裂或错位，积累能量以地震波传播并引起地面震动。地下最初破裂处为震源，震源垂直投影到地面的点为震中，二者之间垂直距离为震源深度。

### 3. 类型辨析

滑坡是斜坡岩土体沿滑动面整体下滑，发生在斜坡，水可增重、润滑并提高孔隙水压力；泥石流是水、泥沙和石块混合物沿陡峻沟谷高速流动，短时间大量水是必要动力。二者都受重力、地形和松散物影响，也可由暴雨地震和工程活动触发。

### 4. 区域分析

西南地势起伏大、坡陡谷深，构造活动和地震频繁使岩体破碎、松散物丰富；季风降雨集中、暴雨多，地下水活动强，具备触发条件。修路、采矿、切坡、弃渣和植被破坏可能降低坡体稳定并增加物源；河谷聚落道路密集提高暴露度。

### 5. 教材活动：灾害关联性

地震可直接引发崩塌、滑坡、泥石流、火灾、海啸、堰塞和有毒气体泄漏等。示例：地震→山体滑坡→滑坡体堵塞河道→形成堰塞湖→堰塞坝溃决→下游洪水。每个箭头分别由震动失稳、物体阻水、蓄水和坝体破坏连接。

### 6. 防治评价

仅植树不足。植被可减少浅层侵蚀并拦截部分径流，但深层滑坡、极端暴雨和沟内已有大量松散物仍可能形成泥石流，且村庄位于沟口堆积通道，暴露度很高。应开展风险评估和监测，建设拦砂、排导工程，严格管理上游弃渣；对高风险居民优先搬迁避让，设置预警和撤离路线。
