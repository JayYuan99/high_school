## 一、本章知识主线

本章把“元素化合物”“氧化还原”“实验探究”“材料科学”和“化学计算”连接起来：

1. 从物质类别认识铁的氧化物、氢氧化物和盐的通性。
2. 从元素价态认识 $Fe$、$Fe^{2+}$、$Fe^{3+}$ 的氧化还原转化。
3. 用实验现象、显色检验和离子方程式建立证据链。
4. 用组成—结构—性能—用途解释合金的设计与选择。
5. 用物质的量处理反应中的质量、溶液浓度和气体体积。

## 二、铁元素双视角网络

### 1. 物质类别

$$
Fe\rightarrow Fe^{2+}/Fe^{3+}\rightarrow Fe(OH)_{2}/Fe(OH)_{3}\rightarrow FeO/Fe_{2}O_{3}
$$

横向处理盐与碱生成沉淀、氢氧化物与酸、氢氧化物受热分解等类别转化。

### 2. 元素价态

$$
Fe(0)\xrightleftharpoons[\text{强还原剂}]{\text{较弱氧化剂}}Fe^{2+}\xrightleftharpoons[\text{还原剂}]{\text{氧化剂}}Fe^{3+}
$$

纵向处理电子转移。$Fe$ 主要表现还原性；$Fe^{3+}$ 主要表现氧化性；$Fe^{2+}$ 处于中间价态，兼有氧化性和还原性。

## 三、实验诊断路径

实验答题统一使用：

```text
取样与对照 → 加试剂 → 描述可观察现象 → 判断微粒变化 → 写离子方程式 → 得出有边界的结论
```

高频特征：$Fe^{3+}$ 遇 $KSCN$ 溶液显红色；$Fe(OH)_{2}$ 从白色迅速变灰绿并最终成为红褐色 $Fe(OH)_{3}$；酸性 $KMnO_{4}$ 被 $Fe^{2+}$ 还原而褪色。

## 四、金属材料选择框架

| 场景 | 关键需求 | 代表材料 |
| --- | --- | --- |
| 井盖、机座 | 硬度、抗压、便于铸造 | 生铁 |
| 机械和交通结构 | 综合机械性能、可加工 | 钢 |
| 餐具、医疗器械 | 耐腐蚀、强度 | 不锈钢 |
| 飞机外壳 | 密度小、强度高、耐腐蚀 | 铝合金 |
| 深海耐压结构 | 强度大、耐腐蚀 | 钛合金 |
| 发动机叶片 | 高温强度、耐热 | 耐热合金 |
| 氢能储运 | 可逆吸放氢 | 储氢合金 |

材料选择还要考虑成本、资源、加工、回收、安全和环境影响，不能只比较单一性能。

## 五、综合计算路径

$$
n=\frac{m}{M}=cV=\frac{V_{\text{气}}}{V_{m}}
$$

计算时先写并配平方程式，把已知量转成物质的量，判断限量试剂，按计量数比求目标物质的量，再转换为目标单位。矿石和合金题还要乘纯度或质量分数。

## 六、高频易混辨析

| 易混内容 | 正确认识 |
| --- | --- |
| 铁与不同氧化剂的产物 | 较弱氧化剂通常生成 $Fe^{2+}$，强氧化剂可生成 $Fe^{3+}$ |
| $Fe_{3}O_{4}$ 的铁价态 | 同时含 $Fe^{2+}$ 和 $Fe^{3+}$ |
| $KSCN$ 检验现象 | 溶液显红色，不是红色沉淀 |
| $Fe^{2+}$ 的性质 | 既有氧化性又有还原性，通常还原性更常见 |
| 铝活泼与耐腐蚀 | 铝活泼并迅速生成致密氧化膜，膜提供保护 |
| 合金性能 | 具体取决于组成与结构，不能使用“一定更好”等绝对结论 |

## 七、章末自测

1. 写出 $Fe$、$Fe^{2+}$、$Fe^{3+}$ 两两转化的三条代表性离子方程式。
2. 设计实验区分 $FeCl_{2}$ 与 $FeCl_{3}$ 溶液，并说明结论边界。
3. 解释合金硬度常比纯金属大的微观原因，并说明为什么不能断言合金所有性能都更好。
4. $2.7\ \mathrm{g}$ $Al$ 与足量 $NaOH$ 溶液反应，求标准状况下生成 $H_{2}$ 的体积。
5. 含 $80.0\%$ $Fe_{2}O_{3}$ 的矿石 $100\ \mathrm{t}$，理论上含铁多少吨？

## 八、章末自测答案

1. 示例：$Fe+2H^{+}=Fe^{2+}+H_{2}\uparrow$；$2Fe^{2+}+Cl_{2}=2Fe^{3+}+2Cl^{-}$；$2Fe^{3+}+Fe=3Fe^{2+}$。试剂可替换，但须符合氧化还原方向并配平。
2. 取样分别滴加 $KSCN$，立即显红色的是 $FeCl_{3}$；不显红色的样品再加入少量氯水和 $KSCN$，随后显红色可支持原样品含 $Fe^{2+}$。若未知样品可能混合两种离子，还需分样并排除原有 $Fe^{3+}$ 干扰。
3. 合金中不同大小的原子扰乱规则排列，使原子层相对滑动更困难，许多合金因而硬度、强度提高。但性能还受组成、组织和制备条件影响，提高某项性能可能牺牲另一项性能。
4. $n(Al)=2.7/27=0.100\ \mathrm{mol}$；由 $2Al\sim3H_{2}$，$n(H_{2})=0.150\ \mathrm{mol}$，$V(H_{2})=0.150\times22.4=3.36\ \mathrm{L}$。
5. $Fe_{2}O_{3}$ 中铁的质量分数为 $112/160=70.0\%$，因此铁的质量为 $100\times80.0\%\times70.0\%=56.0\ \mathrm{t}$。
