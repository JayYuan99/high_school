# 试卷文档结构说明

此套资料按原题重排，不包含答案、手写批注和解题过程。

## Word（.docx）的可编辑结构

- `word/document.xml`：题干、选项和填空使用 Word 原生段落/文本 Run（`w:p`、`w:r`、`w:t`）；第 1、11、19 题表格等使用 Word 原生表格（`w:tbl`）。
- `word/styles.xml`：标题、题干、选项、图文样式。
- `word/media/exam-svg-*.svg`：共 11 张 SVG 矢量示意图，支持 Word 现代版本缩放。
- `word/media/image*.png`：兼容部分老版 Office / LibreOffice 的 PNG 预览图。PNG 是图示备用渲染版本，题干和表格仍是可编辑文字。
- `word/_rels/document.xml.rels`：图片的资源引用关系；插图通过 `a:blip` 的 SVG 扩展（`asvg:svgBlip`）引用矢量图，并保留 PNG 回退。

## Markdown 文件及资源

- `高一化学十月阶段性测试_B卷_原题整理版.md`：标准 Markdown，保留标题层级、表格、题号、选项和公式 Unicode 字符。
- `svg/`：11 张独立 SVG，Markdown 中通过相对路径 `![说明](svg/图名.svg)` 引用，无需 OCR 或整页截图。

**兼容性：** 常用 Markdown 查看器支持外部 SVG；将 Word 转 Markdown 时优先导出文本与表格，并将 SVG 单独复制到相邻 `svg/` 目录即可保留矢量图。
