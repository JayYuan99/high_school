# 高中选科全指南

> 从认识新高考规则、理解学科差异，到完成专业核验、组合比较与最终决策。

高中选科不是简单地挑三门“容易得分”的科目，而是在个人优势、学习意愿、学校条件和未来专业方向之间，做出一个有依据、能解释、可复盘的长期选择。本专题将选科拆成一条完整路径，帮助学生和家长逐步建立判断，而不是被一次考试或一种“热门组合”牵着走。

## 专题定位

本专题面向高中选科决策，适合作为学生自学材料、家长陪伴阅读资料、班会或家长讲座的内容底稿，也可以进一步整理为《高中选科指南》或阶段性复习手册。

专题不提供适用于所有人的“标准答案”，重点解决四个问题：

1. 看懂本省新高考规则，知道选科会影响什么；
2. 理解六门选考科目的学习特点，判断自己是否适合；
3. 把大学专业要求、个人数据和学校条件放在一起比较；
4. 形成可说明理由的选择，并安排选科后的学习与调整。

## 适用对象

- 初三升高一、正在适应高中学习的学生；
- 高一阶段准备选科或正在比较组合的学生；
- 希望参与孩子选科决策的家长；
- 班主任、生涯规划教师和需要组织选科说明活动的教师；
- 尚未确定大学专业方向、希望尽量保留未来选择空间的学生。

## 先记住三条原则

### 1. 规则看本省

考试模式、选科方式、成绩呈现、选科确认时间和学校走班安排，都可能因省份和学校而不同。涉及政策的问题，先查本省教育考试院和学校通知。

### 2. 专业看具体要求

高校专业的选考要求不能只看专业名称，也不能只参考其他省份或其他学校的经验。查询时应结合“学校 + 专业 + 本省年份”，最终以高考当年公布的招生专业目录、院校招生章程等正式信息为准。

### 3. 选择看长期适配

一次考试的高低、同学的选择和别人眼中的“热门组合”，都不能单独决定选科。更可靠的判断依据是：专业资格、连续成绩、相对竞争力、学习意愿、投入产出和学校条件。

## 建议阅读方式

### 如果刚开始了解选科

先阅读[认识新高考与选科](01-认识新高考与选科/)，建立规则和时间意识；再阅读[认识学科与组合](02-认识学科与组合/)和[学科讲解](03-学科讲解/)，不要急着套用别人推荐的组合。

### 如果已经开始比较科目

重点阅读[认识自己](04-认识自己/)和[连接大学专业与职业](05-连接大学专业与职业/)，同时使用[选科前自我评估表](09-实用工具与附录/01-选科前自我评估表.md)、[学科优势记录表](09-实用工具与附录/02-学科优势记录表.md)和[大学专业调查表](09-实用工具与附录/04-大学专业调查表.md)，把“我觉得适合”变成可核对的证据。

### 如果已经有两三个候选组合

阅读[完成选科决策](06-完成选科决策/)，使用[候选组合评分表](09-实用工具与附录/03-候选组合评分表.md)进行比较，再结合[家长与学生沟通清单](09-实用工具与附录/05-家长与学生沟通清单.md)完成讨论，最后用[选科最终确认清单](09-实用工具与附录/06-选科最终确认清单.md)逐项核对。

### 如果已经完成选科

不要把选科当成决策终点。继续阅读[选科后的学习与调整](07-选科后的学习与调整/)，把选择落实为学科学习计划、错题复盘、专业信息跟踪和阶段性检查。

## 一套可执行的决策流程

可以把选科过程压缩为以下五步：

1. **确认规则**：明确本省考试模式、选科范围、成绩计算方式、确认节点和学校安排；
2. **盘点方向**：列出最想读、可以接受和暂时不考虑的专业或职业方向；
3. **记录数据**：收集多次有代表性的考试成绩、排名、波动、错因和学习投入情况；
4. **核验门槛**：查询目标学校和专业的选考要求，确认哪些科目会影响报考资格；
5. **比较并确认**：保留两到三个候选组合，综合专业匹配、学科实力、稳定性、学习意愿和学校条件，完成沟通与最终确认。

这五步不是一次性完成的。新信息出现、成绩趋势变化或专业方向调整时，可以重新比较，但每次调整都应留下理由和依据。

## 维护原则

- 涉及本省考试模式、赋分方式、选科时间、走班安排和高校专业要求的内容，均以最新官方信息为准；
- 政策或招生要求发生变化时，优先更新相关正文和工具表，并在文中标明核验范围；
- 每篇文章尽量先给出关键结论，再解释规则、分析情况、补充案例和行动建议；
- 避免使用“唯一正确组合”“所有人都应该选”等绝对化表述，明确适用条件和可能限制；
- 文章中的建议应建立在连续数据和具体目标上，不以一次考试、单一排名或他人经验代替判断；
- 本目录只保留整理后的学习资料，不放置教材 PDF、原始试卷或其他原始资料。

## 信息核验提醒

选科涉及政策、课程安排和高校招生要求，具有明显的地区性和时效性。阅读本专题时，请按以下顺序核验：

1. 本省教育考试院或招生考试机构发布的政策；
2. 所在学校发布的课程、走班和选科安排；
3. 目标高校当年招生章程及本省招生专业目录。

如果三类信息之间出现差异，以适用于本人所在省份和招生年份的正式信息为准。
