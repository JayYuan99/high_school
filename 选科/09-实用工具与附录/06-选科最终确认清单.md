# 选科最终确认清单

## 使用说明

建议在学校提交选科前，由学生与家长共同逐项确认；无法确认的项目应先补充信息。

- [ ] 已了解本省新高考模式及相关官方政策
- [ ] 已了解学校选科、走班与调整安排
- [ ] 已查看至少 3—5 次考试数据及排名趋势
- [ ] 已查询目标专业、院校的选科要求
- [ ] 已形成并比较至少两个候选组合
- [ ] 已比较不同组合的学习压力与投入
- [ ] 已考虑大学专业受限与备选方向
- [ ] 已与任课教师沟通优势与风险
- [ ] 已与家长充分讨论真实意愿与依据
- [ ] 最终决定不是因为跟随同学
- [ ] 已记录本次决定的依据、日期与后续复盘节点
