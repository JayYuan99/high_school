# 06 选科最终确认清单

## 这张表解决什么问题？

选科提交前，家庭常常只记得“最终组合是什么”，却忘了检查专业要求、学校开班、学习压力、备用方案和复盘节点。本清单用于提交前做最后一次系统核验。

它不是学校报名表，也不能替代本省当年政策和本校正式流程。任何涉及提交、修改、走班和考试的事项，都应以学校通知为准。

## 使用说明

建议由学生和家长共同完成，最好在学校规定的提交截止时间前预留足够时间。无法确认的项目不要勾选，先写入“未确认事项”。

## 一、政策与学校条件

- [ ] 已了解本省新高考模式、选科方式和相关官方政策。
- [ ] 已确认本校选科提交、走班和课程安排的正式通知。
- [ ] 已确认最终组合确实开设，或已确认学校提供的替代方案。
- [ ] 已了解对应组合的师资、课表和教学进度。
- [ ] 已确认选科调整的时间、条件、流程和联系人。
- [ ] 已记录政策或学校信息的来源与日期。

## 二、数据与学科判断

- [ ] 已查看至少 3—5 次测评和相对位置趋势。
- [ ] 已记录三门候选科目的每周实际投入。
- [ ] 已区分知识、方法、审题、计算、表达和状态错误。
- [ ] 已检查主要错误是否在订正后减少。
- [ ] 已考虑课程难度变化对学习投入和成绩稳定性的影响。
- [ ] 学生能够用自己的话解释为什么保留这三门科目。

## 三、专业与组合核验

- [ ] 已列出必须保留、可以接受和暂不考虑的专业方向。
- [ ] 已按招生省份、适用年份、院校和专业（组）逐行核验选科要求。
- [ ] 已记录“均须、任选、必选、不限”等要求类型，未只抄科目名称。
- [ ] 已区分“具备报考资格”和“适合长期学习”。
- [ ] 已比较至少两个候选组合，而非一开始只看一个答案。
- [ ] 已写明最终组合的主要收益和主要代价。
- [ ] 已核对组合是否会限制自己最重视的专业方向。

## 四、家庭沟通与决策分工

- [ ] 学生已经表达真实意愿、学习感受和可承受投入。
- [ ] 家长已经说明信息来源和风险担忧，而不是只给出结论。
- [ ] 双方已经讨论主要分歧，并把未确认事项列出来。
- [ ] 已与任课教师或年级组沟通优势、风险和学校条件。
- [ ] 最终决定不是单纯因为跟随同学、网络排名或一次考试。
- [ ] 学生和家长都知道最终选择的主要代价。

## 七、提交后的复盘安排

选科确认不是学习计划的终点。请提前写下复盘节点：

| 复盘时间 | 要检查什么 | 记录在哪里 |
|---|---|---|
| 选科后第 2—4 周 | 新课适应、作业完成、主要错误 | 学科优势记录表 |
| 高二首月结束 | 三科投入、趋势和方法效果 | 学科优势记录表 |
| 阶段测评后 | 成绩变化、目标专业和学校信息 | 评分表/专业调查表 |
| 学校规定的调整节点前 | 是否需要正式咨询或保持原方案 | 沟通清单/学校通知 |
