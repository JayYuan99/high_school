# 01 选科前自我评估表

## 这张表解决什么问题？

选科前最容易出现的判断是：“我感觉物理不错”“我不喜欢化学”“大家都说地理容易”。这些话可以作为感受记录，但不能直接作为选科结论。

本表用于建立第一轮学科画像，把六科的表现、投入、学习任务、兴趣、问题和专业方向放在一起看。它是选科流程的起点，不是一次填写后自动生成答案的测试。

## 使用说明

建议在一个相对完整的观察周期后填写，最好参考最近 3—5 次测评、作业、错题和教师反馈。填写时请记录日期和资料范围：

|---|---|
| 学生 |  |

| 填写日期 |  |
| 参考时间范围 | 例如：最近 8 周/最近 5 次测评 |
| 当前选科阶段 | 初步了解/候选比较/提交前复核 |
| 参与填写人 | 学生/家长/教师共同填写 |

### 填写顺序

1. 先记录事实：成绩、排名或百分位、投入时间、错因和教师反馈。
2. 再记录感受：喜欢什么、回避什么、愿意长期承担什么任务。
3. 最后写判断：稳定优势、保留观察、谨慎选择和待核验事项。

### 第一轮判断怎么写？

可以使用以下三种标记：

- **稳定优势：** 连续表现较稳定，投入可承受，错误有修复迹象；
- **保留观察：** 有潜力但数据不足，或正在经历方法、老师、章节变化；
- **谨慎选择：** 长期高投入低提升，核心任务持续回避，或专业与学校条件存在明显限制。

这三个词描述的是当前阶段的决策状态，不是给学生贴能力标签。

## 六、填写后的下一步

- [ ] 使用[学科优势记录表](02-学科优势记录表.md)连续记录 8—12 周或至少 5 次测评。
- [ ] 将必须保留的专业方向填入[大学专业调查表](04-大学专业调查表.md)。
- [ ] 至少保留 2 个候选组合，不要过早锁定唯一答案。
- [ ] 对信息不足的项目标记“待核验”，写出来源和完成日期。
- [ ] 数据积累后，再使用[候选组合评分表](03-候选组合评分表.md)比较。

## 使用边界

本表记录的是当前状态，不代表永久能力，也不替代本省官方政策、学校正式通知、教师判断和具体院校专业要求。若课程难度、学习状态或目标方向发生变化，应重新填写或更新相关部分。
