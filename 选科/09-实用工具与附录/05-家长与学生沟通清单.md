# 05 家长与学生沟通清单

## 这张表解决什么问题？

选科讨论很容易变成“家长说前景，学生说压力”，双方都有道理，却没有共同的证据和下一步。沟通清单不是家长审问表，也不是要求学生独自承担选择，而是帮助双方把事实、分歧和行动写清楚。

## 一、会前准备

- [ ] 学生带来最近 3—5 次测评、作业和错题记录。
- [ ] 学生写出三门愿意保留的科目及理由，理由包含证据。
- [ ] 家长准备目标专业、院校和选科要求的来源，不只带来网络截图。
- [ ] 双方确认本次讨论只解决 1—2 个主要问题。
- [ ] 已知晓学校开班、走班和调整政策的查询渠道。
- [ ] 约定讨论中不使用“你必须”“这门没前途”等替代分析的结论。

## 二、学生先说：我怎么看自己的学习

学生可以先独立完成下面内容，再在沟通中表达：

| 问题 | 我的回答和证据 |
|---|---|
| 我目前最稳定的两到三门科目是什么？ |  |
| 每门科目最近的相对位置和变化怎样？ |  |
| 我愿意长期处理哪些核心学习任务？ |  |
| 我最担心哪个科目？具体困难是什么？ |  |
| 哪些困难已经尝试修复？结果如何？ |  |
| 我希望保留哪些专业方向？为什么？ |  |
| 我能承受的每周学习投入大约是多少？ |  |
| 如果最终选择不符合预期，我最担心的后果是什么？ |  |

学生表达的是第一手学习体验，但仍需和连续数据、教师反馈及专业信息对照。

## 四、共同核验的问题

- [ ] 我们讨论的是连续数据，还是只记住了一次考试？
- [ ] “喜欢/不喜欢”具体对应哪项核心学习任务？
- [ ] 目标专业是否已经查到具体省份、年份、院校和专业（组）？
- [ ] 候选组合是否至少保留两个？各自的主要代价是什么？
- [ ] 学校是否能开设、走班和提供相应师资？
- [ ] 如果课程难度上升或成绩波动，准备观察多久再复盘？
- [ ] 如果候选组合不能开设，备用方案是什么？

## 七、沟通规则

1. 先听学生完整说明，再提出建议；
2. 用具体证据替代“别人都这样”“以后肯定有用”；
3. 家长可以提出风险，但不直接替学生宣布结论；
4. 学生可以表达不愿意，但需要说明具体原因和愿意核验的替代方案；
5. 争议信息查不到时，写入待核验清单，不用猜测填空；
6. 一次沟通结束时，必须留下负责人、动作和日期。

## 九、沟通后的下一步

- [ ] 将已确认的信息带回[候选组合评分表](03-候选组合评分表.md)。
- [ ] 将未确认事项逐一查清并记录来源。
- [ ] 提交前共同完成[选科最终确认清单](06-选科最终确认清单.md)。
- [ ] 如果选科后出现成绩波动，先回到[学科优势记录表](02-学科优势记录表.md)记录，而不是立即争论“是不是选错”。

**使用边界：** 沟通清单用于改善共同决策，不保证家长和学生结论一致；涉及政策、专业要求和学校安排时，以正式信息为准。
