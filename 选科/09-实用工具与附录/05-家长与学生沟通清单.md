# 家长与学生沟通清单

## 使用说明

建议在双方均看过成绩记录、专业调查和候选组合后共同填写。讨论目标是澄清依据与分歧，不是替对方做决定。

## 共同讨论事项

- [ ] 学生未来可能发展的专业方向
- [ ] 六科真实成绩、排名与变化趋势
- [ ] 每门学科的学习投入和主要困难
- [ ] 学校师资、走班与开班条件
- [ ] 不同组合对应的专业限制
- [ ] 学生的真实意愿与可承受压力
- [ ] 最坏情况下的备选方案

## 沟通原则

- 优先讨论数据、专业要求和行动方案，避免只用情绪或标签判断。
- 给学生表达真实意愿的空间；家长可提出风险提醒，但不替代学生成长中的决策练习。
