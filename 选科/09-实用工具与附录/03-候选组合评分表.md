# 候选组合评分表

## 使用说明

先完成专业调查和学科观察，再选择 2—3 个候选组合评分。可调整权重，但应写明调整理由。

| 指标 | 建议权重 | 组合 A | 组合 B | 组合 C | 评分依据/证据 |
|---|---:|---:|---:|---:|---|
| 专业匹配度 | 35 |  |  |  |  |
| 学科竞争力 | 25 |  |  |  |  |
| 成绩稳定性 | 15 |  |  |  |  |
| 学习兴趣 | 10 |  |  |  |  |
| 学习投入 | 10 |  |  |  |  |
| 学校教学资源 | 5 |  |  |  |  |
| 总分 | 100 |  |  |  |  |

## 风险复核

- [ ] 是否限制最想报考的专业？
- [ ] 是否只依据一次成绩或他人意见？
- [ ] 三门科目的学习压力是否过度集中？
- [ ] 学校是否能稳定开设该组合？
- [ ] 是否有备选组合？

## 使用提醒

评分最高不自动等于最适合。提交前仍要完成[选科最终确认清单](06-选科最终确认清单.md)。
